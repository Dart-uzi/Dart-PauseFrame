Client-only Fabric mod for Minecraft 26.3.

## Features

- FPS limit on the vanilla Pause screen
- FPS limit on the Settings/Options screen
- Separate FPS limits for inventories, containers, chat, mod screens and other vanilla screens
- Per-category enable/disable switches
- FPS values from 1 to 260
- Config button on the vanilla Pause screen
- Configuration saved to `config/pause_fps_limiter.json`
- Does not modify Minecraft's normal Max Framerate setting
- Returning from the config screen restores the previous screen

## Dependencies

- Fabric API

## Installation

1. Install Minecraft 26.3 with Fabric Loader.
2. Install the required version of Fabric API.
3. Put the mod `.jar` file into the `mods` folder.
4. Start Minecraft.

## Configuration

Open the vanilla Pause screen and use the **FPS** button to open the mod configuration.
